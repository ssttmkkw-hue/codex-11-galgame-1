# 引擎接入

## 原图与画幅

所有文件保留内置生图工具输出，没有通过脚本重绘、抠图、缩放或裁切。

- 角色：1024 × 1536，RGBA，包含透明背景。使用普通 Alpha 混合，不要把黑色 RGB 底误当作实底或再次色键抠图。
- 横图：1536 × 1024，原生 3:2。对 1920 × 1080 游戏界面，可由引擎使用居中 `cover`；显示源图中间约 864 像素高，上下各裁约 80 像素。关键人物脸部与背景主体按中心安全区构图，但仍应逐场景审阅。
- 如需完整展示横图，可使用 `contain` 并加色底；不要拉伸为 16:9。
- 立绘使用同一画布尺寸与约定姿态，但它们是整张重新生成的差分，并非可逐像素拼接的分层原画。换表情推荐 100–180 ms 交叉淡化；轮廓微移时可直接切换。

## 锚点与显示建议

立绘建议使用底部中心锚点 `(0.5, 1.0)`，双人横向位置约为屏宽的 `0.28` / `0.72`。如果显示完整全身，让图像高度约等于舞台高度的 94%；对话近景则可放大到舞台高度的 118%，向下移出 18%，由舞台边界裁切。

以上锚点针对整张画布，包含原图透明留边。原图脚底并非精确贴在画布最后一行；若项目需要像素级站位，在引擎中逐图微调偏移，并记录到项目专用配置。不要对差分各自做自动紧裁，否则切换时更容易跳动。

## 路径与清单

`assets/manifest.json` 中每个条目的 `path` 都相对于仓库根目录。包含 `id`、分类、实际宽高、图像模式、Alpha 极值（立绘）、字节数、SHA-256、人物和表情标签。可按该清单预加载或构建引擎资源表。

```js
const sprite = `assets/characters/${character}/${expression}.png`;
// character: natsumi | mio
// expression: neutral | smile | shy | surprised | serious | sad
```

## 本地预览

`preview/index.html` 是素材审阅工具：切换场景和两人的表情，查看全身与对话构图，使用透明棋盘检查边缘。该工具不保存剧情进度，也不是完整游戏。

预览通过普通 `<script src="catalog.js">` 读取自动生成的清单，因此直接以 `file://` 打开也无需发起跨源 JSON 请求。所有图片引用均为相对路径，离线可用。
